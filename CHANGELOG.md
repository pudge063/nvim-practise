# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [Unreleased]

### Added
- Виртуальная файловая система в памяти (`js/filesystem.js`) — `ls`,
  `cd`, `pwd`, `mkdir`, `touch`, `cat`, `rm`, `vim <файл>` (ADR-0002).
- Эмулятор vim с нуля (`js/vim.js`), без сторонних библиотек: режимы
  Normal/Insert/Visual/Visual-Line/Command-line; движения
  `h j k l w b e 0 ^ $ gg G f{char}` с числовыми повторителями;
  операторы `d y c` + `iw`/`aw`; `x r p P o O i a I A`; `u`/`Ctrl-r`;
  поиск `/ n N`; command-line `:w :q :wq :{N} :sort :'<,'>sort
  :s/../../ :%s/../../g` (ADR-0003).
- 17 заданий в 5 категориях (Движение, Слова и выделение, Поиск,
  Сортировка и команды, Редактирование) с проверкой по финальному
  состоянию буфера, а не по логу нажатий, и кнопкой подсказки
  (ADR-0004).
- Стеклянный терминал с анимированным градиентным фоном, чисто
  HTML/CSS/JS без фреймворков (ADR-0001).
- `docker/Dockerfile` + `docker-compose.yml` — локальный запуск на
  `nginx:alpine`, `http://localhost:80`, без build-стадии (ADR-0005).
- `tests/vim.spec.mjs` — 21 тест движка vim на встроенном
  Node test runner (`node --test`), без зависимостей.
- ADR-0001..0005, README, этот CHANGELOG.

### Fixed
Найдено при живом прогоне через headless-браузер (Playwright, вручную,
не входит в репозиторий) до первого коммита — фиксирую как обычные
находки прогона, а не как отдельный релиз:
- `cd ~` не резолвился (тильда не разворачивалась в путь) —
  `FileSystem.normalize()` теперь разворачивает `~` и `~/...` в
  `/home/user`.
- Пути заданий (`practice/*.txt`) были относительными — открытие
  задания после `cd` в другой каталог падало с необработанным
  исключением при попытке записать файл не туда. Пути заданий теперь
  абсолютные (`/home/user/practice/*.txt`), не зависят от текущего
  `cwd` шелла.
- `:q` в vim бросал `TypeError: Cannot read properties of null` в
  консоль (движок уже обнулён колбэком `onQuit`, а код рендера всё
  равно пытался прочитать его состояние) — `terminal.js` теперь
  проверяет, что движок ещё жив, перед повторным рендером.

### Known limitations (см. соответствующие ADR)
- Файловая система не переживает перезагрузку страницы (ADR-0002).
- vim-движок не поддерживает: именованные регистры, метки, макросы,
  `.`-повтор, folds, splits/tabs, `t/T/F`+`;`/`,`, текстовые объекты
  кроме `iw`/`aw`, visual block mode (ADR-0003).
- DOM-слой (`terminal.js`, `tasks.js`) пока без автотестов — только
  ручная проверка в браузере.
